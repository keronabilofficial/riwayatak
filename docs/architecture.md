# معمارية «روايتك بالعربية»

## نطاق النسخة الأولى

تُبنى المنصة حول دورة محتوى مركزية تبدأ بالمؤلف، ثم الرواية، ثم الفصول، وتنتهي بتجربة قراءة عامة متوافقة أصيلًا مع اللغة العربية واتجاه RTL. المحتوى الأدبي لا ينشئه الجمهور؛ بل يديره أصحاب الصلاحيات عبر لوحة التحكم، بينما يستطيع الزائر الاستكشاف والقراءة، ويستطيع المستخدم المسجل حفظ تقدمه ومتابعة الأعمال التي تهمه.

## نموذج المحتوى

| الكيان | الغرض | العلاقات الأساسية |
| --- | --- | --- |
| `authors` | ملف مؤلف مستقل ومرئي للجمهور | يملك عدة روايات، وله صورة اختيارية من `media` |
| `novels` | العمل الأدبي ووصفه وحالة نشره | يتبع مؤلفًا رئيسيًا، وله فصول وغلاف وتصنيفات ووسوم |
| `chapters` | وحدة القراءة والنشر | تتبع رواية واحدة، وترتيبها يحدد إداريًا عبر `sortOrder` |
| `categories` و`tags` | الاكتشاف والتصنيف المرن | ترتبط بالروايات بعلاقات متعددة إلى متعددة |
| `media` | مرجع ملف خارجي فقط | يخزن المفتاح والرابط والبيانات الوصفية، لا يخزن البايتات |

تُستمد الروابط العامة من `slug` ثابت. بعد نشر الرواية أو ملف المؤلف لا يُعاد توليد الرابط؛ ويُعامل تغيير الاسم على أنه تغيير للعنوان الظاهر لا للرابط المعتمد لمحركات البحث.

## النشر والصلاحيات

تمر الرواية والفصل بالحالات: `draft` و`review` و`published` و`unpublished` و`archived`. لا تعرض الخدمات العامة إلا المحتوى المنشور، بينما تسمح صلاحيات الإدارة بعرض المسودات وإدارتها. تعتمد المنصة أدوار `user` و`editor` و`admin` و`super_admin`، وتُفرض العمليات الحساسة في الخادم وليس في الواجهة فقط.

## تجربة المستخدم والبيانات التشغيلية

يحتفظ النظام بعلاقات متابعة الروايات والمفضلة وموضع القراءة، إضافة إلى سجل أحداث القراءة والتحليلات. هذا يتيح إظهار مؤشرات إدارية حقيقية مثل المشاهدات والقراءات والنشاط الأخير من دون اختلاق بيانات تقييم أو مراجعات.

## التشغيل والنسخ الاحتياطي

تحتفظ `backup_runs` بسجل غير قابل للتعديل لنتائج النسخ المنطقي، ويتضمن الحالة والموقع الخارجي وقيمة تحقق ووقت الانتهاء وسياسة الاحتفاظ. تُنفذ المهام المجدولة عبر نقاط استقبال مؤمنة بعد نشر المنصة، وتبقى واجهة التخزين ومفاتيح الخدمات الخارجية منفصلة عن الكود. لا تُنشأ مهام فعلية قبل نشر النسخة وإعداد الأسرار ومخزن النسخ المعتمد.
