# ملاحظات تكامل Paymob

- تتطلب واجهة إنشاء نية دفع ترويسة تفويض بصيغة `Authorization: Token <secret key>`.
- تستخدم عملية إنشاء النية مبلغًا بالسنتات، وعملة متوافقة مع معرّف التكامل، ومعرّف/معرّفات طريقة الدفع.
- ينبغي أن يستقبل عنوان `notification_url` إشعارًا بنتيجة المعاملة، وأن يُتحقق من صحة التوقيع باستخدام سر HMAC.
- تحتاج المنصة إلى المفتاح العام والمفتاح السري ومعرّف تكامل البطاقات وسر HMAC، وجميعها تحفظ كأسرار ولا تُسجل في الكود أو قاعدة البيانات.

المصادر: وثائق Paymob الرسمية، صفحة Create Intention وصفحة Authentication Request، تمت مراجعتها في 14 أغسطس 2026.
